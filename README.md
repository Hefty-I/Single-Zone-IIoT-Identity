# Single-Zone-IIoT-Identity# Single-Zone IIoT Decentralized Identity

A simulated identity-management system for one IIoT zone, one fog node, and multiple devices.

## Planned features

- Device registration using initial authentication and ECC keys
- Batch registration with a Merkle tree and inclusion proofs
- Temporary tokens for devices waiting in a batch
- Resource access rules and device revocation
- Attack demonstrations and performance measurements
